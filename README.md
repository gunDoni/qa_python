Тест для примера не в счет
1ый тест: Сделал параметризированный тест для метода set_book_genre с существующим и несуществующим жанром, чтобы проверить, что несуществующий жанр не добавился, а существующий добавился без проблем.
2ой тест: Сделал параметризированный тест для метода get_book_genre с существующей книгой в списке и несуществующей, чтобы проверить, что выведется, при запросе несуществующей книги.
3ий тест: Сделал параметризированный тест для метода add_new_book, чтобы проверить работу с разной длиной книг. Применил немного граничные значения.
4ый тест: Тест для метода get_books_genre, чтобы проверить, что метод возвращает весь словарь книг с жанрами корректно — включая случай, когда жанр не был установлен (несуществующий жанр).
5ый тест: Параметризированный тест для метода get_books_with_specific_genre с существующим и несуществующим жанром, чтобы проверить, что для существующего жанра возвращается список подходящих книг, а для несуществующего — пустой список.
6ой тест: Параметризированный тест для метода get_books_for_children, чтобы проверить три случая: жанр с возрастным рейтингом, жанр без возрастного рейтинга и несуществующий жанр.
7ой тест: Тест для метода add_book_in_favorites, чтобы проверить, что повторное добавление одной и той же книги в избранное не создаёт дубликат.
8ой тест: Параметризированный тест для метода delete_book_from_favorites, чтобы проверить удаление как существующей в избранном книги, так и попытку удалить книгу, которой там нет.
9ый тест: Тест для методов add_book_in_favorites и get_list_of_favorites_books, чтобы проверить, что в избранное добавляются только книги, существующие в общем списке, и итоговый список избранного формируется корректно.
